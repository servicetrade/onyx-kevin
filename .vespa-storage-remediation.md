# Vespa Storage Remediation Plan

## Problem Summary

Users are reporting poor search results and seeing "507 Insufficient Storage" errors from Vespa. Root cause: Vespa is running out of disk space (reaches 85% threshold configured in `services.xml.jinja`).

## Immediate Actions Taken

1. Created diagnostic script to check:
   - Host disk space
   - Vespa container disk usage
   - Docker volume size
   - Document counts
   - Connector status

2. Provided cleanup options:
   - Orphan document cleanup (safest)
   - Inactive connector deletion
   - Full re-index (last resort)

## Long-Term Prevention Strategies

### 1. Monitor Vespa Storage Proactively

**Add monitoring alerts:**

```bash
# Add to cron or monitoring system
*/30 * * * * /root/check_vespa_storage.sh
```

```bash
#!/bin/bash
# check_vespa_storage.sh
VESPA_ID=$(docker ps --filter name=index --format '{{.ID}}')
USAGE=$(docker exec $VESPA_ID df /opt/vespa/var | tail -1 | awk '{print $5}' | sed 's/%//')

if [ "$USAGE" -gt 75 ]; then
    echo "WARNING: Vespa storage at ${USAGE}%" | mail -s "Vespa Storage Alert" ops@example.com
fi
```

### 2. Increase Vespa Disk Allocation

**Option A: Increase host disk space**
- Expand the host VM's disk
- Or move Docker to a larger volume

**Option B: Set explicit Docker volume size limit (not recommended - can cause data loss)**
- Docker volumes don't have native size limits
- Better to ensure host has adequate space

**Option C: Move to Kubernetes with proper PVC**
- Use Helm chart with larger storage: `vespa.storage: 100Gi`

### 3. Reduce Storage Footprint

#### A. Use Smaller Embedding Models

Current default: `nomic-ai/nomic-embed-text-v1` (768 dimensions)

**Edit: `backend/onyx/configs/model_configs.py`**

```python
# Switch to smaller model
DOC_EMBEDDING_CONTEXT_SIZE = 512  # Reduce if possible
```

Or configure a smaller model via the UI:
- e5-small-v2: 384 dimensions (50% less storage than 768)
- MiniLM-L6: 384 dimensions

#### B. Verify BFLOAT16 Precision is Enabled

Check in database that embedding models use BFLOAT16 (not FLOAT):

```sql
SELECT
    model_name,
    model_dim,
    normalize,
    query_prefix,
    passage_prefix,
    embedding_precision  -- Should be 'bfloat16'
FROM embedding_model;
```

If any show 'float', update them to 'bfloat16' to save 50% storage.
