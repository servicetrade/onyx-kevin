Claude 4.5 Model Upgrade - Rollback Instructions
===================================================
Use these instructions to revert to the pre-upgrade state if needed.

Pre-upgrade state (servicetrade branch @ 0d5cfa373):
  - litellm 1.66.3, openai 1.75.0, langchain-openai 0.2.9, llama-index 0.12.28
  - Bedrock default model: anthropic.claude-3-5-sonnet-20241022-v2:0
  - Anthropic defaults: claude-3-7-sonnet-20250219 / claude-3-5-sonnet-20241022

Rollback Steps
--------------

1. Switch back to the servicetrade branch

   cd /root/danswer
   git fetch && git checkout servicetrade && git pull

2. Rebuild the Docker image with the old code

   docker build -t onyxdotapp/onyx-backend:latest -f backend/Dockerfile backend/

3. Restart the stack

   cd /root/danswer/deployment/docker_compose
   docker-compose -f docker-compose.prod-no-letsencrypt.yml -p danswer-stack down
   docker-compose -f docker-compose.prod-no-letsencrypt.yml -p danswer-stack up -d

4. Wait for containers and Vespa

   docker ps --format "table {{.Names}}\t{{.Status}}"

   Vespa will need 20-30+ minutes to reload its index. Monitor:
   docker exec danswer-stack-index-1 curl -s http://localhost:8081/state/v1/health | grep code

5. Restore the old model configuration in the database

   # Check current state
   docker exec -it danswer-stack-relational_db-1 psql -U postgres -d postgres \
     -c "SELECT id, name FROM llm_provider;"

   docker exec -it danswer-stack-relational_db-1 psql -U postgres -d postgres \
     -c "SELECT * FROM model_configuration;"

   # Clear the Claude 4.5 model configurations
   docker exec -it danswer-stack-relational_db-1 psql -U postgres -d postgres \
     -c "DELETE FROM model_configuration;"

   # Restore the old Bedrock model (adjust llm_provider_id if not 3)
   docker exec -it danswer-stack-relational_db-1 psql -U postgres -d postgres \
     -c "INSERT INTO model_configuration (name, is_visible, llm_provider_id, max_input_tokens) VALUES ('anthropic.claude-3-5-sonnet-20241022-v2:0', true, 3, 200000);"

   # Restore the old default model
   docker exec -it danswer-stack-relational_db-1 psql -U postgres -d postgres \
     -c "UPDATE llm_provider SET default_model_name = 'anthropic.claude-3-5-sonnet-20241022-v2:0' WHERE name = 'AWS Bedrock';"

6. Verify

   - Log in at https://kevin-staging.servicetrade.com
   - Model dropdown should show the old Claude 3.5 Sonnet model
   - Send a test message to confirm chat works
   - Try a search query to confirm RAG works

Notes
-----
- The full stack restart means another 20-30+ minute Vespa loading wait.
  Plan accordingly.
- If you only need to rollback the models (not the code), you can skip
  steps 1-3 and just run the SQL in step 5, then restart only api_server:
  docker-compose -f docker-compose.prod-no-letsencrypt.yml -p danswer-stack restart api_server
- The feb-new-models branch and PR #4 will still exist for re-deployment later.
