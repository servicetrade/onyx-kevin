# Problem Context: Missing Sidebar Assistants

## Problem Summary
After upgrading Kevin AI (forked Onyx) from v0.28.2 to v2.5.9, the sidebar no longer shows assistants. The UI structure changed significantly.

## Expected Behavior (Production v0.28.2)
Sidebar shows:
- "My Documents" link
- **Assistants** section with list: Default, ServiceTrade Corp, Sales Assistant, Search, General, Paraphrase
- "Explore Assistants" link
- **Chats** section with history

## Observed Behavior (Staging v2.5.9)
Sidebar shows:
- **Agents** section with ONLY "Explore Agents" link (no assistant list!)
- **Projects** section with "New Project"
- **Recents** section with chat history
- NO "My Documents" link
- NO list of assistants/agents

## Key Code Discovery
In `web/src/sections/sidebar/AppSidebar.tsx`:
- Line 131: `const { pinnedAgents, setPinnedAgents, currentAgent } = useAgentsContext();`
- Line 148-151: `visibleAgents` is built from `pinnedAgents` + `currentAgent`
- Line 458-459: Sidebar renders `visibleAgents.map(...)` - only pinned agents show!

**The v2.5.9 UI changed from showing ALL visible assistants to only showing PINNED agents.**

## Root Cause Hypothesis
Users have no "pinned agents" after the upgrade, so the sidebar is empty. The data model changed from "visible assistants" to "pinned agents".

## Environment
- Server: kevin-staging.servicetrade.com
- Deployment: `/root/danswer/deployment/docker_compose`
- Containers: `danswer-stack-*` (using `docker-compose -f docker-compose.prod-no-letsencrypt.yml -p danswer-stack`)
- Database: PostgreSQL in `danswer-stack-relational_db-1`

## Database State (Verified)
```sql
SELECT id, name, deleted, is_visible, is_public FROM persona WHERE id IN (-3, -2, -1);
```
Result:
```
 id |    name    | deleted | is_visible | is_public
----+------------+---------+------------+-----------
 -1 | General    | f       | t          | t
 -3 | Art        | f       | t          | t
 -2 | Paraphrase | f       | t          | t
```

All flags look correct:
- `deleted = false`
- `is_visible = true`
- `is_public = true`

## Fixes Already Attempted
1. Set `is_visible = true` for built-in personas - No effect
2. Set `is_public = true` for built-in personas - No effect
3. Cleared `hidden_assistants = '[]'` for user - No effect
4. Set `deleted = false` for built-in personas - No effect
5. Restarted API server - No effect
6. User logged out/in, refreshed page - No effect
