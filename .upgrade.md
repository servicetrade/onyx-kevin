# Onyx v2.5.9 Upgrade Instructions

## Pre-requisites
- Snapshot of staging server taken (for rollback)
- Branch `servicetrade-upgrade-dec2025` already has all code fixes merged

## Important: Container Naming
The staging server uses `./restart-onyx.sh` which runs:
- Compose file: `docker-compose.prod-no-letsencrypt.yml`
- Project name: `danswer-stack`

So containers are named:
- `danswer-stack-api_server-1`
- `danswer-stack-nginx-1`
- `danswer-stack-relational_db-1`
- etc.

**DO NOT use plain `docker-compose` commands** - always use `./restart-onyx.sh` or specify the file and project name explicitly.

## On Staging Server

### 1. Stop Services (Clean)
```bash
cd /root/danswer/deployment/docker_compose
docker-compose -f docker-compose.prod-no-letsencrypt.yml -p danswer-stack down
```

### 2. Pull Latest Code
```bash
cd /root/danswer
git fetch origin
git checkout servicetrade-upgrade-dec2025
git pull
```

### 3. Rebuild Images
The deployment uses pre-built images, so we must rebuild to get code changes:
```bash
cd /root/danswer
docker build -t onyxdotapp/onyx-backend:latest -f backend/Dockerfile backend/
docker build -t onyxdotapp/onyx-web-server:latest -f web/Dockerfile web/
```

### 4. Start Services
```bash
cd /root/danswer/deployment/docker_compose
./restart-onyx.sh
```

Or manually:
```bash
docker-compose -f docker-compose.prod-no-letsencrypt.yml -p danswer-stack up -d --build --force-recreate
```

### 5. Verify Deployment
```bash
# Check all containers are running (should be 12)
docker-compose -f docker-compose.prod-no-letsencrypt.yml -p danswer-stack ps

# Verify migrations ran (single head, no errors)
docker exec danswer-stack-api_server-1 alembic heads

# Check API server logs - look for "Application startup complete"
docker logs danswer-stack-api_server-1 --tail 30

# Check nginx is healthy (not restarting)
docker logs danswer-stack-nginx-1 --tail 10
```

### 6. Test in Browser
- Navigate to https://kevin.servicetrade.com
- Verify login works
- Verify LLM provider settings are intact

## Troubleshooting

### If nginx keeps restarting
Check logs: `docker logs danswer-stack-nginx-1 --tail 20`
- If "module not found" error, ensure you pulled latest code (run-nginx.sh fix)

### If "multiple heads" migration error
This shouldn't happen - the problematic migration was deleted. If it does:
```bash
docker exec -it danswer-stack-api_server-1 alembic heads
```
Should show single head.

### If port 80 already allocated
```bash
docker stop $(docker ps -aq) && sleep 2 && ./restart-onyx.sh
```
