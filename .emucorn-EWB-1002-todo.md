# Implementation Plan: EWB-1002 - Fix Missing Sidebar Assistants After v2.5.9 Upgrade

**Story Type**: Full-stack (Frontend primary fix, Backend testing, Configuration)
**Estimated Tasks**: 7 tasks
**Approach**: Fix the root cause in `AppProvider.tsx` where `null` pinned_assistants is incorrectly converted to empty array `[]`, preventing the default persona fallback from triggering. Add backend test coverage for edge cases. Configure staging to match production behavior.

## Key Decisions

- **Primary Fix Location**: `AppProvider.tsx:42` - change `|| []` to `?? undefined` to preserve null and trigger default persona fallback in `getPinnedAgents()`
- **Type Safety**: Update `AgentsProviderProps.pinnedAgentIds` type from `number[]` to `number[] | undefined` to properly handle null case
- **Backend Migration NOT needed**: Frontend fix is cleaner than SQL migration - existing users with NULL will see defaults, users with explicit `[]` (intentionally unpinned all) will see empty (correct behavior)
- **TDD for Backend**: Add test case for empty array `[]` vs null distinction since this is a coverage gap
- **No Frontend Tests**: Frontend components don't have established test patterns in this codebase
