## Technical Learnings

### Vespa Storage
- Vespa has 85% disk threshold in `services.xml.jinja` - exceeding causes 507 errors
- Check disk usage: `docker exec danswer-stack-index-1 df -h /opt/vespa/var`
- Vespa volume: `vespa_volume:/opt/vespa/var`

### Search Ranking
- Recency bias formula: `max(1 / (1 + decay_factor * age_years), 0.75)`
- Floor of 0.75 means old docs only get 25% penalty at most
- `recency_bias` options: BASE_DECAY, FAVOR_RECENT, NO_DECAY, AUTO
- `BASE_RECENCY_DECAY = 0.5`, `FAVOR_RECENT_DECAY_MULTIPLIER = 2.0`

### LLM Filter Extraction
- Extracts source_type and time_cutoff from natural language queries
- Controlled by `enable_auto_detect_filters` in RetrievalDetails
- **BUG**: Frontend doesn't send this field, defaults to None, treated as False
- Persona setting `llm_filter_extraction` is checked second but never reached due to bug

### Useful SQL Queries
```sql
-- Check persona settings
SELECT id, name, is_default_persona, llm_filter_extraction, recency_bias
FROM persona WHERE is_default_persona = true OR id = 0 OR name = 'Default';

-- Check connector status
SELECT c.name, c.source, ccp.last_successful_index_time, ccp.last_attempt_status
FROM connector c JOIN connector_credential_pair ccp ON c.id = ccp.connector_id
WHERE c.source IN ('GONG', 'ZENDESK') ORDER BY ccp.last_successful_index_time DESC;

-- Check recent documents
SELECT source, COUNT(*) as doc_count, MAX(doc_updated_at) as latest
FROM document WHERE doc_updated_at > NOW() - INTERVAL '60 days'
GROUP BY source ORDER BY doc_count DESC;

-- Check index errors
SELECT error_msg, COUNT(*) FROM index_attempt_errors
WHERE time_created > NOW() - INTERVAL '7 days' GROUP BY error_msg;
```
